# 🔳 QR Code Generator

A simple and responsive **QR Code Generator** built using **HTML, CSS, and JavaScript**. The application allows users to instantly generate QR codes for text, URLs, or any custom input.

## 🚀 Features

- Generate QR codes from text or URLs
- Responsive and user-friendly interface
- Real-time QR code generation
- Input validation for empty fields
- Works directly in the browser without installation

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- QR Code API

## 📂 Project Structure

```text
QR-Code-Generator/
│
├── index.html

├── script.js
├── README.md
└── .gitignore
```

## ▶️ How to Use

1. Open `index.html` in your web browser.
2. Enter any text or URL.
3. Click **Generate QR Code**.
4. The generated QR code will appear instantly.
